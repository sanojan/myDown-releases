# myDown

A Windows app for downloading videos, audio and images, built on [yt-dlp](https://github.com/yt-dlp/yt-dlp) and [gallery-dl](https://github.com/mikf/gallery-dl).

## Download

**[⬇ Download the latest installer](https://github.com/sanojan/myDown-releases/releases/latest)**: open the release and run `myDown-Setup-<version>.exe`.

- Windows 10/11, 64-bit. No admin rights needed; everything (FFmpeg included) is bundled.
- Windows SmartScreen may warn about an unrecognised app because the installer isn't code-signed. Click **More info → Run anyway**.
- Once installed, myDown updates itself: it checks this page daily and installs new versions with one click.

## Features

- Videos from YouTube, Vimeo, Facebook, X and [many more sites](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md): choose quality and format, audio-only (MP3, M4A, FLAC…), or cut out just a part.
- Instagram posts, carousels, reels, stories, highlights and whole profiles, plus Pinterest, Tumblr, Flickr and others.
- Log in with your browser (Firefox recommended) or a cookies.txt file for private or members-only content.
- Download queue, presets, searchable history.
- Watch list: follow channels and profiles and get new uploads automatically.
- Tray icon, notifications, start with Windows, automatic engine updates.

Please respect the terms of the sites you download from and the rights of creators.
